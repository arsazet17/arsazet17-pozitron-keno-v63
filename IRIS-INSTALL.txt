ПОЗИТРОН KENO v6.3.12 — ОБНОВЛЕНИЕ IRIS

Репозиторий: arsazet17/arsazet17-pozitron-keno-v63

1. Распакуйте POZITRON-KENO-v6.3.12-IRIS-UPDATE.zip.
2. Загрузите его содержимое в КОРЕНЬ существующего репозитория, рядом с index.html.
   Существующие одноимённые файлы замените. Папки scripts и .github сохраните на своих местах.
3. Зафиксируйте изменения. Дождитесь публикации GitHub Pages и запуска тестов Iris.
4. Откройте приложение. На экране должна быть версия 6.3.12.

ZIP обновления НЕ содержит JSON-архивы: свежие тиражи и прогнозы не будут затёрты.
Не удаляйте данные сайта и не очищайте хранилище браузера: там есть локальные серии.
Прежние серии доступны в «Архив → Прежние версии» и продолжают свои пять проверок.
Новые серии появятся только при разрешении A. Пустой список при A НЕТ — нормальное поведение.

ПОЛНЫЙ ZIP исходников — отдельная резервная копия присланного проекта с правками.
Не загружайте из полной копии старые JSON-архивы поверх более свежих файлов репозитория.

Основные изменения: самостоятельные фигуры, A по рядам/перегреву, независимые MINI,
отдельная выборка B, выплаты 3–10 из существующей таблицы, архив по пяти шагам,
карта 1–80 с объяснением, журнал A, статистика по размеру, отдельная проверка 700.
