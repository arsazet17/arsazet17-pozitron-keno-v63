# ПОЗИТРОН КЕНО 6.3

Новая облегчённая версия.

## Главный экран
- 3 последних тиража.
- Выпадение / Возрастание / Вместе.
- Переходные числа подсвечиваются оранжевым.
- Локальная база НЕ рисуется до проверки сети.

## Инструменты
1. FINGERPRINT
   - LOGIC
   - ANTILOGIC
   - внутренний архив FINGERPRINT
   - единый горизонт 🎯 / ⏳−1
   - переходы, реальный Manhattan, состояние матрицы, М1–М20, исторические состояния
   - контролируемое обучение весов только после фактического результата
2. МАТРИЦА
   - сжатие / разжатие
   - плотность
   - центр массы
   - баланс квадрантов
3. М1–М20
   - горизонтали
   - вертикали
   - давление/продолжение по местам
